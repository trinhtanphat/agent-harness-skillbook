Cài 60 Agent Skills vào dự án của bạn

Sử dụng Node.js 22+, không cần npm package hoặc API. Mặc định chỉ xem trước và không thay đổi file nào.

Xem 60 skillĐọc 14 hướng dẫnHướng dẫn Markdown nguồn

1. Lấy mã nguồn

git clone https://github.com/trinhtanphat/agent-harness-skillbook.git
cd agent-harness-skillbook
node scripts/install-skills.mjs --list

2. Xem trước, không ghi dữ liệu

node scripts/install-skills.mjs --skill complete-repository-mirror --target /path/to/your-project

Chọn dự án đích đã tồn tại và thuộc phạm vi bạn được phép chỉnh sửa. Khi không có --write, script chỉ in danh sách dự kiến và SHA-256 của nguồn.

3. Chỉ cài khi bạn sẵn sàng

# Cài một skill vào .agents/skills
node scripts/install-skills.mjs --skill complete-repository-mirror --target /path/to/your-project --write

# Cài tất cả 60 skill
node scripts/install-skills.mjs --all --target /path/to/your-project --write

# Hoặc dùng .claude/skills và .github/skills
node scripts/install-skills.mjs --skill complete-repository-mirror --format claude --target /path/to/your-project --write
node scripts/install-skills.mjs --skill complete-repository-mirror --format github --target /path/to/your-project --write

4. Xác minh an toàn

Trình cài từ chối ID không nằm trong danh mục, thư mục đích là symlink và skill đã có. Nó không ghi đè bản cũ, không truy cập credential, không tải file qua mạng. Nếu muốn thay đổi skill đã cài, tự xem diff và phê duyệt thủ công.

node scripts/test-install-skills.mjs

Lưu ý

Việc cài SKILL.md không đồng nghĩa agent đã nạp hoặc hỗ trợ toàn bộ kỹ năng. Hãy kiểm tra cách đọc skills và chính sách quyền của ứng dụng agent bạn sử dụng.
