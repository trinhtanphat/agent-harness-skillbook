# Release gate template

- Project / Environment:
- Branch / Commit SHA:
- Artifact SHA:
- Test commands and logs:
- Reviewer / approval:
- [ ] Permission and scope confirmed
- [ ] Static, unit, contract, integration, E2E complete
- [ ] Visual, hardware (if needed) and asset rights reviewed
- [ ] Backup and restore rehearsal (when applicable)
- [ ] Readiness checked with current SHA
- [ ] Rollback rehearsed
- [ ] Postdeploy runtime and user journey verified
- Blockers:
- Decision: PASS / PARTIAL / BLOCKED
